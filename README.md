# PlotFrameToPDF

одуль AutoLISP для экспорта выделенной рамкой области чертежа AutoCAD в PDF.

## озможности

- кспорт прямоугольной области, заданной «резиновой» рамкой.
- стройство печати: DWG To PDF.pc3.
- Стиль печати: monochrome.ctb (ч/б) или acad.ctb (цвет).
- втоподбор формата A3..4A0 по количеству объектов и габаритам рамки.
- втоматическая ориентация: книжная / альбомная.
- Сохранение PDF в %TEMP%\PlotFramePDF\ или в пользовательскую папку.
- втоматическое открытие готового PDF в просмотрщике.

## становка

1. Сохранить PlotFrameToPDF.lsp в кодировке CP1251 (ANSI) без BOM.
2.  AutoCAD выполнить: (load "D:/PlotFrameToPDF/PlotFrameToPDF.lsp")
   или подключить через APPLOAD.

## сновные команды

| оманда | азначение |
|---|---|
| С / EXPTPDF | кспорт области в PDF |
| Т | ключить цветную печать |
|  | ернуть ч/б печать |
|  | ыбрать папку экспорта |
| Т | Сбросить папку на %TEMP%\PlotFramePDF\ |
| Т | оказать таблицу форматов |
| СТТ | оказать текущие настройки |
|  | Список доступных форматов в PC3 |
| СТ | далить все PDF из папки экспорта |

## астройки

    (setq *pfp-color-mode* T)              ; цветная печать
    (setq *pfp-output-dir* "D:/PDF")       ; своя папка
    (setq *pfp-size-factor* 2.0)           ; множитель габаритов
    (setq *pfp-open-delay* 500)            ; задержка перед открытием

## История изменений

### 3.11
- Печать по умолчанию идёт через ActiveX (`Layout` + `Plot.PlotToFile`), команда -ПЕЧАТЬ больше не используется: набор её вопросов зависит от вкладки Модель/Лист и версии AutoCAD, из-за чего ответы «съезжали» (PDF с именем «_N», вопрос «Продолжить построение?»).
- Диалоги печати подавляются: `QuietErrorMode` + `PAPERUPDATE=1` на время печати (диалог «размер бумаги не найден» больше не появляется при первом запуске в заново открытом файле).
- Выбранный формат проверяется по фактическому списку media name устройства DWG To PDF.pc3 (команда ПФПМЕДИА); отсутствующие форматы (например, 2A0/4A0) заменяются ближайшим существующим с сообщением в командной строке.
- Новые переменные: `*pfp-engine*` ("activex" | "command" — запасной механизм через -ПЕЧАТЬ), `*pfp-keep-page-setup*` (nil — вернуть настройки листа после печати).

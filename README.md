# PlotFrameToPDF

одуль AutoLISP для экспорта выделенной рамкой области чертежа AutoCAD в PDF.

## озможности

- кспорт прямоугольной области, заданной «резиновой» рамкой.
- стройство печати: DWG To PDF.pc3.
- Стиль печати: monochrome.ctb (ч/б) или acad.ctb (цвет).
- втоподбор формата A3..4A0 по количеству объектов и габаритам рамки.
- втоматическая ориентация: книжная / альбомная.
- Сохранение PDF в %TEMP%\PlotFramePDF\ или в пользовательскую папку.
- втоматическое открытие готового PDF в просмотрщике.

## становка

1. Файл PlotFrameToPDF.lsp хранить в кодировке CP1251 (ANSI) без BOM.
2. Вариант A (просто): в AutoCAD выполнить
   (load "D:/PlotFrameToPDF/PlotFrameToPDF.lsp")
3. Вариант B (рекомендуется при работе с AutoExtraction): положить файл
   в папку Plugins проекта AutoExtraction и грузить командой RELOAD
   (раздел плагинов, см. ниже).

## Тихий PDF-принтер (однократная настройка)

В штатном `DWG To PDF.pc3` может быть включена галочка «Показывать результаты в программе просмотра» — тогда AutoCAD сам открывает каждый отпечатанный лист (вкладки просмотрщика, блокировка удаления файлов). Модуль печатает через принтер из глобальной `*psp-pc3*` (по умолчанию `PlotSPDSToPDF.pc3`). Чтобы создать такую копию:

1. Откройте папку принтеров: в консоли AutoCAD выполните `(startapp "explorer.exe" (getenv "PrinterConfigDir"))` (команда ПЛОТТЕРМАНАДЖЕР может не открываться — не страшно).
2. Скопируйте `DWG To PDF.pc3`, переименуйте копию в `PlotSPDSToPDF.pc3`.
3. Двойной клик по копии → «Пользовательские свойства…» → снять флажок **«Показывать результаты в программе просмотра»** → OK → сохранить.
4. Имя уже задано в модуле по умолчанию; переопределить после загрузки: `(setq *psp-pc3* "PlotSPDSToPDF.pc3")`.

Если копии нет, экспорт упадёт с «устройство не найдено» — тогда после загрузки: `(setq *psp-pc3* "DWG To PDF.pc3")`. Тот же порядок печатает команда **ПСППОМОЩЬ / PSPHELP**.

## Настройки (ПСПНАСТРОЙКИ / PSPSET)

Диалог настроек SPDS-модуля. Хранение — реестр (setcfg), восстанавливаются при каждой загрузке модуля.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Папка сохранения PDF | пусто (temp) | куда переносится собранный альбом (папка создаётся); пусто = `%TEMP%\PlotFramePDF` |
| PDF-принтер (pc3) | PlotSPDSToPDF.pc3 | «тихая» копия DWG To PDF.pc3 без автооткрытия листов |
| Автосборка при листах БОЛЬШЕ | 3 | больше N — склейка без вопроса, N и меньше — вопрос «Да/Нет» |
| Задержка открытия, с | 5 | пауза перед открытием результата (Ghostscript должен закрыть файл) |
| Открывать результат | да | склейка или одиночные листы |
| Удалять одиночные после склейки | да | волна ~задержка + повторные попытки ~1 мин |

Ghostscript по-прежнему собирает во временную папку (путь без кириллицы надёжнее), альбом переносится в настроенную папку, открытие — уже оттуда. Одиночные листы всегда остаются во временной папке.

Заглушка **PlotFrameToFP.lsp** — отдельный (FP) вариант модуля, реализация запланирована; туда же войдут настройки качества печати базового модуля.

## Интеграция с RELOAD (AutoExtraction)

- Файл модуля размещается в `Plugins\PlotFrameToPDF.lsp` проекта AutoExtraction.
- В `reload.lsp` — отдельный список плагинов `*ae-reload-plugin-files*`.
- Модуль несёт маркер редакции `(ред. N` в шапке — попадает в счётчик «Маркер редакции» RELOAD.
- Кодировка CP1251 без BOM; в `.gitattributes` проекта-потребителя для `Plugins/*.lsp` отключить преобразование переводов строк (`-text`).
- Проверка после RELOAD: баннер «PlotFrameToPDF.lsp v3.17», команды доступны (ЭКСВПДФ / EXPTPDF / ОЧИСТПДФ / ПФПТАБЛ / ПФПСТАТ / ПФПМЕДИА / ПФПЦВЕТ / ПФПЧБ / ПФППАПКА / ПФПТЕМП), ПФПСТАТ печатает настройки.

## Модуль PlotSPDSToPDF.lsp (СПДС GraphiCS)

Отдельный модуль для экспорта объектов форматов СПДС GraphiCS (примитив SPDSFORMAT) в PDF. **Два файла**, загружать строго в этом порядке:

```
(load "D:/PlotFrameToPDF/PlotSPDSToPDF.lsp")   ; ядро + экспорт (31 Кб)
(load "D:/PlotFrameToPDF/PlotSPDSDiag.lsp")    ; диагностика (19 Кб)
```

(Версия 0.9 приписывала сбои пределу размера файла ~36 Кбайт; лог 0.10 это опроверг — причина была в одной функции диагностики, см. историю.)

| Команда | Псевдоним | Файл | Назначение |
|---|---|---|---|
| ЭКССПДСДИАГ | SPDSDIAG | PlotSPDSDiag.lsp | Диагностика: свойства формат/лист/листов, каналы чтения, габариты, дамп объекта, журнал spds_diag.txt |
| ЭКССПДСВПДФ | SPDSTOPDF | PlotSPDSToPDF.lsp | Серийная печать выбранных форматов: сортировка по листам, бумага на шаг вверх (A4->A3...), файлы s01.pdf... |
| ПСППАПКА | PSPPAPKA | PlotSPDSToPDF.lsp | Открыть папку журналов и сборок (%TEMP%\PlotFramePDF) в Проводнике |

Порядок внедрения: сначала ЭКССПДСДИАГ в файле с рамками СПДС — по её выводу уточняются каналы чтения свойств; затем серийная печать; сборка в один многостраничный PDF — следующий этап. Кодировка CP1251, без BOM.
